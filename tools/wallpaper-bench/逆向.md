# 官方引擎逆向

壁纸要做到和官方手机版一样，有两个来源。官方安装包里 `assets/` 下是引擎素材的源码：着色器、公共头文件、基础贴图、示例壁纸，第 549 版起已经照着用了。素材之外的行为都在原生库 `lib/arm64-v8a/libscenejni.so` 里（41MB），比如粒子各项参数的默认值、3D 模型和骨骼的文件格式、属性脚本怎么跑。这份文档讲后者怎么查。

官方素材、反汇编结果、符号表都只放在工作区（`/home/claude/weapk`），不提交到任何仓库。仓库里只放方法、工具和自己写的结论。

## 一、拿到安装包

用户把官方安卓版（`io.wallpaperengine.weclient`）放在 ppt 仓库「大肥鱼」那个发布里：

```bash
mkdir -p /home/claude/weapk/x && cd /home/claude/weapk
curl -sL -o base.1.apk "https://github.com/dhhd1426-ops/ppt/releases/download/%E5%A4%A7%E8%82%A5%E9%B1%BC/base.1.apk"
cd x && unzip -qo ../base.1.apk 'assets/*'      # 素材源码
```

`curl` 被拦时用 `gh api repos/dhhd1426-ops/ppt/releases`，找到 `base.1.apk` 那个 asset 的 id，再用 `gh api -H "Accept: application/octet-stream" repos/dhhd1426-ops/ppt/releases/assets/<id> > base.1.apk` 下载。

## 二、安装包里有什么

- **Java/Kotlin 层**（`classes.dex`、`classes2.dex`）只管界面、播放列表、和电脑配对传文件。包名 `io.wallpaperengine.weclient`（Activity、`WEWallpaperService`）、`io.wallpaperengine.wedata`（数据类）、`io.wallpaperengine.wrapper.SceneLib`（JNI 入口）。渲染的事这里不用看。
- **原生引擎** `libscenejni.so`：**符号没去掉**，5 万多个函数都带 C++ 名字，这是查得动的关键。里面能认出的组件：
  - V8（`cppgc::`、`unibrow::`）：SceneScript 是用 V8 跑的。我们用断网的 WebView 跑，行为是一致的。
  - JsonCpp（`Json::`）、rapidjson：读场景和材质的 JSON。
  - msdfgen：文字层用多通道距离场字体。
  - 引擎自己的类：`Scene`、`ImageLayer`、`EffectLayer`、`TextLayer`、`ShapeLayer`、`AnimationLayer`、`ParticleSystem`、`ParticleCommands`、`MdlData`、`Animation`、`IK`、`Material`、`MaterialSystem`、`FboSystem`、`Camera`、`Light`、`PropertySystem`、`SceneScriptEngine`、`DataCache`、`GLGraphicsBackEnd`。
- **JNI 接口**（`SceneLib_*`）就是官方 App 对引擎能做的全部操作，可以对照着看我们缺什么：`initScene`、`updateScene`、`resizeScene`、`sendTouchInput`、`sendGravityInput`（重力感应视差）、`sendNormalizedParallaxOffset`（桌面滑屏视差）、`sendFreeAlignmentXForm`（自由取景）、`sendAudioData`（频谱）、`applySceneProperties`、`getSceneProperties`、`getSceneFeatureFlags`、`getWallpaperResolution`、`getSceneCanvasSize`。

## 三、工具

这边能用 `readelf`、`c++filt`、`strings`、`llvm-objdump-18`（能反汇编 aarch64）。没有 jadx、Ghidra、capstone，网络关着也装不了。

`tools/wallpaper-bench/re.sh` 把常用操作包了起来（第一次运行时会解出 so 并生成 `so/syms.txt`）：

```bash
re.sh syms 'ParticleCommands::'                 # 列函数：地址 大小 名字
re.sh dis  'ParticleCommands::OperatorAlphaFadeDefaults'   # 反汇编一个函数
re.sh str  'alphafade|colorrandom'              # 引擎里的字符串（JSON 键、着色器名、报错文本）
re.sh xref 'alphafade'                          # 哪个函数用到了这个字符串（这里查出来是 DataCache::ParseParticleCommandBuffers）
```

查一个 JSON 键是什么意思，固定走这条路：先用 `str` 确认引擎认这个键，再用 `xref` 找到解析它的函数，然后 `dis` 那个函数和它调用的 `*Defaults` 函数。默认值一般是 `fmov` 指令里的浮点立即数，或者从 `.rodata` 用 `ldr` 读出来的常量。

## 四、查过的结论和线索

- **粒子**：每种组件都有一个 `ParticleCommands::<名字>Defaults` 函数，**官方默认值就在里面**。之前靠猜写的默认值（`alphafade` 0.5/0.5、`colorrandom` 0–255）应该照这些函数核对一遍。
  - 发射器：`EmitterBoxRandom`、`EmitterSphereRandom`、`EmitterLayerImage`（从图层像素发射）。
  - 初始化器：`AlphaRandom`、`AngularVelocityRandom`、`ColorList`、`ColorRandom`、`HSVColorRandom`、`InheritControlPointVelocity`、`InheritInitialValueFromEvent`、`LifetimeRandom`、`MapSequenceAroundControlPoint`、`MapSequenceBetweenControlPoints`、`PositionOffsetRandom`、`RemapInitialValue`、`RotationRandom`、`SizeRandom`、`TurbulentVelocityRandom`、`VelocityRandom`。
  - 运算器：`AlphaChange`、`AlphaFade`、`AngularMovement`、`Blending`、`Boids`、`CapVelocity`、`Collision*`（平面、方块、球、四边形、模型）、`ColorChange`、`ControlPointAttract`、`InheritValueFromEvent`、`MaintainDistance*`，另外字符串里还有 `vortex`、`turbulence`、`reducemovementnearcontrolpoint`。
  - 渲染器：`spritetrail`、`ropetrail`、`rope`。
  - `ChildDefaults` 对应子粒子（children），`ControlPointDefaults` 对应控制点，`AudioProcessingDefaults` 对应跟着音乐变化。
- **3D 模型和骨骼（puppet）**：`.mdl` 文件，读取入口是 `MdlData::ParseInMemory`。文件里有三段标识：`MDLV` 是网格（顶点和三角形）、`MDLS` 是骨骼（`MDLS0004`）、`MDLA` 是动画（`MDLA0006`）。骨骼相关的函数还有 `ConvertMdlBonesToLocalSpace`、`ParseBoneConstraints`、`Animation::InterpolateSIMDBones*`（混合动画）、`IK::SolveIKSet`、`IK::SimulateIKSetVerlet`（物理晃动）。官方包里能拿来对照的样本只有 `assets/models/editor/camera/camera.mdl`，带人物骨骼的样本要用户发 `.mpkg`。
- **属性脚本**：`SceneScriptEngine::`（72 个函数）和 `SceneScriptAdapter::`。图层上能让脚本调用的方法都叫 `ImageLayer::PropertyFunction*`，比如 `GetBoneTransform`、`SetBoneTransform`、`ApplyBonePhysicsImpulse`，照这些名字就能列出脚本 API 的全表。

## 五、注意

- `xref` 是按「`adrp` 取页地址 + `add` 取页内偏移」的写法找的，能覆盖大多数引用，但不是全部。找不到时可以换成搜字符串前后相邻的字符串，或者从调用方往下找。
- `strings -t x` 给的是文件偏移。这个 so 的只读数据段里文件偏移和虚拟地址一样，所以能直接拿来比。如果换了新版本安装包，先用 `readelf -lW` 核对一下是否还一样。
- 官方版本更新后，素材和 so 都要重新取，结论要重新核对。现在用的这份 `base.1.apk` 是第 549 版那会儿用户给的。
